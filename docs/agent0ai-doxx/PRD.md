# Product Requirements Document (PRD)

## Product Name
AI Goal Journal & Accountability Coach

## Objective
Help users maintain daily journals, automatically extract goals and blockers using AI, and improve accountability through progress tracking and structured insights.

## Target Users
- Students
- Developers
- Professionals
- Individuals working on personal goals

## Core Requirements

### Authentication
- User registration
- User login/logout
- Firebase authentication support

### User Management
- Create/sync user profile
- View profile
- Update profile information

### Journal Management
- Create journal entry
- View journal history
- Edit journal entry
- Delete journal entry

### AI Features
- Extract goals
- Detect completed activities
- Identify blockers
- Generate structured JSON output

### Non-Functional Requirements
- Modular architecture
- RESTful APIs
- Reusable frontend components
- Easy AI-agent onboarding using `PROJECT_CONTEXT.md`

## MVP Scope
- Firebase Authentication
- User Profile APIs
- Journal CRUD APIs
- Gemini-based journal analysis
- Basic dashboard and journal history UI
